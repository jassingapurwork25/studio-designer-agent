# Prompt: Create a redesign direction

Using the approved audit and project brief, create a distinctive redesign direction for [website/product]. Preserve the brand constraints and existing technical/business requirements.

Use research-benchmark, ux-architecture, creative-direction and design-system skills as needed. Define the audience, desired perception, visual thesis, information architecture, key page compositions, typography direction, semantic color roles, imagery direction, component inventory, responsive behavior and interaction states.

If alternatives help, propose up to three meaningfully different directions and recommend one. Do not implement code yet. Save the proposal to `workspace/REDESIGN_DIRECTION.md`. Do not use generic AI template patterns or invent content/metrics.
