# Prompt: Audit an existing website

Act as Studio Northstar. Audit this website/repository: [URL or repo]. The goal is to identify the most important UX, UI, content, responsive, accessibility, performance and technical issues before redesign.

Scope: [routes/pages or "discover the key routes"]. Audience: [audience or infer from evidence]. Inspect the code and available live pages/screenshots. Do not modify code yet.

Use the design-audit skill and the audit rubric. Record the inspection method, evidence, severity (P0–P3), user impact, recommended fix and effort. Separate confirmed findings from assumptions. Do not invent analytics, user research or performance measurements. Save the report to `workspace/AUDIT_REPORT.md` and return a concise executive summary with the top five priorities. Stop after the report; do not implement changes.
