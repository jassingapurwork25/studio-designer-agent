# Prompt: Implement the approved redesign

Implement the approved redesign in the existing project. First inspect repository structure, Git status, current stack, scripts and relevant routes. Preserve working functionality, APIs, authentication, data structures and existing conventions.

Use design-system, frontend-development, responsive-accessibility and qa-performance skills. Work incrementally. Establish semantic design tokens, implement reusable components, update only the agreed routes, make every visible control functional, and include loading/empty/error/success states where relevant.

Do not deploy, push, delete data, replace the framework, or expose secrets. Run the available build/lint/type/test commands and report exact results. Save a list of changed files and unresolved issues. Stop when the agreed scope and acceptance checklist are complete.
