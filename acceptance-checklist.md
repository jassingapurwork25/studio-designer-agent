# Website Acceptance Checklist

## UX and content
- [ ] Primary value proposition is clear.
- [ ] Main user journey is understandable.
- [ ] Navigation labels are consistent and destinations work.
- [ ] No invented statistics, testimonials or claims.

## Visual quality
- [ ] Typography and spacing use the design system.
- [ ] Hierarchy and alignment are consistent.
- [ ] Images have appropriate crop and aspect ratio.
- [ ] All component states are designed and implemented.

## Responsive
- [ ] 360px and 390px widths checked.
- [ ] Tablet width checked.
- [ ] Desktop width checked.
- [ ] No horizontal overflow or clipped primary action.

## Accessibility
- [ ] Keyboard navigation works.
- [ ] Focus indicators are visible.
- [ ] Inputs have labels and errors.
- [ ] Contrast and motion considerations checked.

## Engineering
- [ ] Build succeeds.
- [ ] Lint/type checks pass where available.
- [ ] Main interactions work.
- [ ] No secrets exposed.
- [ ] Existing business logic and integrations preserved.

## Handoff
- [ ] Changed files summarized.
- [ ] Tests and limitations recorded.
- [ ] Known issues and next steps listed.
