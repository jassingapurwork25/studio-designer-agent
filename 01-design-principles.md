# Product-centered design principles

## Design is a system of decisions
A good interface makes the next useful action clear. Visual polish cannot compensate for confusing navigation, weak content, inaccessible controls, or broken interactions.

## Start with context
Determine:
- Who is using the product and in what environment?
- What are the user's top tasks and constraints?
- What trust signals and content are required?
- What makes this product different from alternatives?
- What must work on mobile, low bandwidth, keyboard, or assistive technology?

## Visual hierarchy
Use scale, contrast, position, whitespace, grouping, and repetition to show importance. Each viewport should have a clear primary focal point. Avoid making every card, metric, and button equally prominent.

## Composition
- Use a consistent content grid and page container.
- Align related objects; use asymmetry only when it improves hierarchy or character.
- Establish section rhythm through spacing and background changes, not endless cards.
- Keep line lengths comfortable for reading.
- Use whitespace as structure, not wasted space.

## Typography
- Select typefaces for brand character, language coverage, legibility, and performance.
- Establish a type scale with clear roles: display, page title, section title, body, label, caption, numeric/data.
- Use appropriate line-height and weight; do not use font size alone to establish hierarchy.
- Test actual content, long names, localized strings, and numbers.

## Color
- Build a role-based palette: canvas, surface, raised surface, text, muted text, border, primary, accent, success, warning, danger, focus.
- Check contrast in all states, not only default.
- Use accent color sparingly to signal action or emphasis.
- Support light/dark themes only when needed and test both systematically.

## Brand and originality
A distinctive result is not the same as decoration. Find a design idea grounded in the product: editorial typography for content-led work, precise tables for data-heavy tools, expressive imagery for culture, restrained motion for premium services, etc.

## Anti-patterns
- Generic hero with vague headline and two buttons
- Repeated same-size cards for every content type
- Excessive gradient backgrounds and glass panels
- Over-rounded controls without a design rationale
- Emoji as navigation or action icons
- Tiny low-contrast text
- Fake ratings, testimonials, partner logos, or metrics
- Desktop-first layouts that collapse poorly
- Motion that delays reading or makes users dizzy
