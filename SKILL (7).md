# Research and Benchmarking

## Trigger
Use when the user requests inspiration, competitor analysis, examples, trends, current products, or reference-based redesign.

## Workflow
1. Define the comparison category, audience, market/geography, and what needs benchmarking.
2. Use Google Search and URL Context when available for current or niche references. Prefer primary product pages and credible case studies.
3. Inspect relevant pages, not only search snippets. Record date accessed, source URL, and what was actually observed.
4. Compare 3–5 useful references across information architecture, typography, visual identity, navigation, content patterns, interaction, mobile behavior, and accessibility.
5. Extract transferable principles, not superficial copying. Explain what should and should not be adapted to the user's product.
6. If images/screenshots cannot be captured by available tools, state this and request screenshots; never present generated mockups as real competitor screenshots.

## Output
A concise benchmark matrix with: reference, audience/category, useful pattern, trade-off, adaptation idea, source URL.

## Rules
- Never copy another site's exact identity, copy, proprietary assets, or layout wholesale.
- Do not state that a trend is current without a recent source.
- Separate observed features from inferred business intent.
