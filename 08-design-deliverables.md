# Deliverables by phase

## Discovery
- Project brief
- User groups and top tasks
- Sitemap and route inventory
- Constraints and assumptions
- Acceptance criteria

## Audit
- Scope and inspection method
- Pages/states inspected
- Prioritized issue log with evidence
- Rubric score and coverage (if requested)
- Quick wins and strategic recommendations

## Redesign
- Creative direction statement
- Moodboard/reference rationale (links, not copied assets)
- Sitemap and key user flows
- Page-level wireframe outline
- Design tokens and component spec
- Responsive and interaction states

## Development
- Updated source code
- Reusable components and tokens
- Functional controls and validation
- Responsive behavior
- Preserved existing integrations and business logic

## QA and handoff
- Build/lint/type/test results
- Manual/automated QA matrix
- Accessibility/performance findings
- Known issues and limitations
- Changed-file list and handoff notes
